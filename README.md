## Project Overview
The Hospital Management System is a console-based Python application designed to streamline hospital operations. It handles patient registration, doctor scheduling, appointment booking, and billing management efficiently using clean, modular code and error handling.

## Features
* Patient record management (Add, view, and search patients).
* Doctor availability tracking and appointment booking.
* Input validation using `try-except` blocks to handle invalid entries.

## Prerequisites & Installation
